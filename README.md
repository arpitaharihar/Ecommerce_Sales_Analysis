# Ecommerce_Sales_Analysis

An end-to-end E-Commerce Sales  built using MySQL and Microsoft Power BI.

The project analyzes sales performance, product performance, regional revenue, customer behavior, and customer segmentation through SQL analysis and an interactive Power BI dashboard.

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to identify:

- Overall sales performance
- Revenue trends over time
- Category and sub-category performance
- Regional and city-wise revenue
- Top-performing products
- Top customers by revenue
- Customer order behavior
- Customer segmentation
- Revenue and quantity relationships

The analysis was performed using MySQL, and the results were transformed into an interactive Power BI dashboard.

---

## 🛠️ Tools & Technologies

- MySQL – Data storage and SQL analysis
- Power BI Desktop – Interactive dashboard and visualization
- Power Query – Data preparation and transformation
- DAX – Measures and calculations
- Microsoft Excel / CSV – Source data handling
- GitHub – Project documentation and version storage
